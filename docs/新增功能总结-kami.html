核心 一、攻击与检测分离（架构重构）

初版中攻击代码直接修改内存对象（victim.setLatitude()），攻击方与检测方共享同一 JVM 对象，即「左手打右手」。重构后攻击走独立报文通道。

  • 新增 AttackInjector —— 攻击只构造恶意 hex 写入报文总线，不再修改 Aircraft 对象
  • 新增 AdsbMessageFactory —— 统一报文编码 + CRC 计算，正常/攻击共用
  • SecurityCheckService.check(msg) —— 收敛为纯报文分析，不读取 source 做判断
  • AdsbMessage / SecurityAlert 增加 source 字段（NORMAL / INJECTED）
实测验证：攻击后飞机真实坐标位移 0.0 km（攻击未污染检测方对象），5 种攻击全部命中、240 条正常报文 0 误报。

量化 二、检测效果量化指标

新增 /api/stats/detection 接口，输出检测效果四项指标，前端面板实时展示。

指标实测含义
检出率 Recall100%注入报文被检测命中的比例
误报率 FPR0.0%正常报文被误判为异常的比例
精确率 Precision100%所有告警均对应真实攻击
F1 分数1.0检出率与精确率的调和平均

地图 三、真实地面站监控功能

依据四川九洲空管地面站技术/操作手册，新增真实空管监控终端功能：

功能出处说明
📏 测距工具操作手册 §4.6地图两点/目标间测距，端点可吸附到飞机
◎ 距离环操作手册 §4.3.3100/200/400km 三层环，圆心可拖动
➤ 航迹矢量线技术手册 §5.10m按航向+速度预测未来位置
🔍 目标过滤器操作手册 §4.4.4按高度层/距离范围/呼号过滤目标
📡 信标机自检技术手册 §6.7周期发射+信号强度监视+性能下降告警
🟢 站点状态报告操作手册 §4.6.4CAT023 风格，良好/降级/过载/故障分级
信标信号强度降到门限以下 → 生成「信标信号异常」告警 → 站点状态自动从「良好」降为「降级」，形成真实自检闭环。

数据 四、真实 ADS-B 数据源接入

  • 新增 RealDataService —— 从 OpenSky Network 公开 API 拉取真实航班（已解码的 ICAO/呼号/经纬度/高度/速度/航向）
  • 接口 POST /api/realtime/import、DELETE /api/realtime
  • 实测成功导入 430+ 架真实航班，单位换算（米→英尺、m/s→节）
  • 地图三色区分：真实航班蓝 / 仿真正常绿 / 异常红
  • 仿真引擎与真实数据隔离：SimulationService 只处理 source=SIMULATION 的飞机

体验 五、前端交互增强

  • 🎬 自动演示模式 —— 一键连续触发 5 种攻击（2.5s 间隔），展示攻击→检测→告警闭环
  • 轨迹断裂变色 —— 状态翻转/位置跳变时封存旧段、开新段（绿→红）
  • SVG 飞机图标随航向旋转 + 光晕脉冲动画
  • 检测指标面板、信标机信号强度滑杆、站点状态页（新路由 /station）

工程 六、数据持久化与健壮性

  • H2 数据库从内存库改为文件库（backend/data/），重启不丢数据
  • Maven 配置阿里云镜像、本机工具链（JDK 17 / Maven / Node 24）搭建
  • 修复：仿真不再污染真实航班、目标过滤器默认不隐藏飞机、距离环标签重叠等
