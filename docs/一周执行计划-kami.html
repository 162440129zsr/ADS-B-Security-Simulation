RID 项目的三条核心启示

RID 做了什么它怎么做的我们直接复用
数据模拟 wifi.py create_packet() 拼二进制包，update_position() Haversine 算轨迹 SimulationService 随机生成飞机 → 每条报文微调经纬度模拟飞行
实时监控 app.py + MapView.vue 后端 1 秒写一次 DB，前端 1 秒 GET 一次刷新 Marker AircraftController 定时写位置 + 前端 3 秒轮询 GET /api/aircraft/positions
安全检测 collision_detection.py detect_collision() 两两算二次方程求碰撞时间，分 high/medium 等级 SecurityCheckService 算位置跳变/高度突变/速度超限，分 红色/橙色/黄色
一句话心法：RID 项目的本质是「产生数据 → 存进数据库 → API 暴露 → 前端轮询展示」。我们的 ADS-B 系统完全同构——把「WiFi 嗅探」换成「ADS-B 报文模拟」，把「无人机」换成「飞机」，剩下全部复用。

#谁做什么
1 熊康 打开 SimulationService.java，写一个 generateRandomAircraft() 方法：随机 ICAO、中国空域经纬度、合理高度速度，插入 aircraft 表
2 熊康 加 @Scheduled(fixedRate = 1000) 定时任务：每秒取出所有飞机，用 Haversine 微调经纬度，生成一条 adsb_message 报文写入数据库
3 赵士睿 执行 npm create vue@latest adsb-frontend，装 Element Plus + Leaflet + Axios + ECharts。参考 RID 的 MapView.vue 先写一个空地图
4 赵士睿 配置 src/router/index.js 6 个路由 + 左侧导航菜单。参考 RID DroneList.vue 写飞机列表占位组件
RID 项目教会我们一件事：不要一开始就追求完美。RID 的 MapView 就是用 setInterval 每秒调一次 API，没有 WebSocket、没有状态管理库，照样能跑。我们的原则是——先跑通，再优化。第一天结束就应该能在数据库里看到模拟报文，前端能看到一个地图。
