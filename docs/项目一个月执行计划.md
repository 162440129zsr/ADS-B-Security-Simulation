### 🔹 Day 2（7/24 周四）—— 数据库设计

**熊康（后端）**:
- [ ] 设计并创建 MySQL 数据库 `adsb_simulation`，包含以下表：

```sql
-- 1. 飞行器信息表
CREATE TABLE aircraft (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    icao VARCHAR(6) NOT NULL UNIQUE COMMENT 'ICAO 24位地址',
    callsign VARCHAR(8) COMMENT '航班呼号',
    category VARCHAR(50) COMMENT '飞机类别',
    status ENUM('正常','异常') DEFAULT '正常',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 2. ADS-B 报文记录表
CREATE TABLE adsb_message (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    icao VARCHAR(6) NOT NULL,
    raw_hex VARCHAR(28) NOT NULL COMMENT '原始28位十六进制报文',
    df INT COMMENT '下行格式',
    tc INT COMMENT '类型码',
    altitude DOUBLE COMMENT '高度(英尺)',
    latitude DOUBLE COMMENT '纬度',
    longitude DOUBLE COMMENT '经度',
    speed DOUBLE COMMENT '速度(节)',
    heading DOUBLE COMMENT '航向角',
    message_type VARCHAR(30) COMMENT '消息类型',
    crc_valid BOOLEAN COMMENT 'CRC是否通过',
    received_at BIGINT COMMENT '接收时间戳',
    is_encrypted BOOLEAN DEFAULT FALSE COMMENT '是否加密报文',
    INDEX idx_icao (icao),
    INDEX idx_received_at (received_at),
    INDEX idx_message_type (message_type)
);

-- 3. 安全告警表
CREATE TABLE security_alert (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    icao VARCHAR(6) NOT NULL,
    alert_type VARCHAR(50) COMMENT '告警类型(位置跳变/高度异常/速度超限/CRC失败/重放攻击)',
    alert_level ENUM('红色','橙色','黄色') DEFAULT '黄色',
    description TEXT COMMENT '告警描述',
    raw_message VARCHAR(28) COMMENT '关联原始报文',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    is_resolved BOOLEAN DEFAULT FALSE,
    INDEX idx_icao (icao),
    INDEX idx_created_at (created_at)
);

-- 4. 仿真控制表
CREATE TABLE simulation_config (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    aircraft_count INT DEFAULT 10 COMMENT '仿真飞机数量',
    message_interval_ms INT DEFAULT 1000 COMMENT '报文发送间隔(毫秒)',
    is_running BOOLEAN DEFAULT FALSE COMMENT '仿真是否运行中',
    attack_type VARCHAR(30) COMMENT '攻击模拟类型(NULL/位置欺骗/数据篡改)',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

- [ ] 用 JPA 创建对应的 Entity 类和 Repository 接口
- [ ] 写一个测试类验证数据库连接和 CRUD

**交付物**: 数据库建好、后端能读写数据。

## ⚠️ 风险提示 & 应对策略

| 风险 | 概率 | 应对 |
|------|:---:|------|
| **加密算法太复杂**，一个月集成不完 | 中 | 先用AES/HMAC做简化版，保证链路能跑通，真算法后续替换 |
| **GNU Radio报文模拟** 对接困难 | 中 | 先用纯软件模拟生成（Java Random + pyModeS逻辑），不依赖硬件 |
| **前端地图** 性能问题（飞机太多） | 低 | 控制模拟飞机数量 ≤ 50，使用聚合Marker |
| **队友不同步**，一人进度落后 | 中 | 每天15分钟同步站会，提前暴露问题 |
| **调试花太多时间** | 中 | 先写单元测试再集成，前3天打好基础很关键 |
