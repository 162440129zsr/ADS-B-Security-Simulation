后端 · Spring Boot 3.3.0 + Java 17

  • AdsbDecoderService — ADS-B 报文解码核心，支持飞机识别、空中/地面位置、速度、运行状态 5 类消息
  • CrcService — CRC-24 多项式校验（0xFFFA0480）
  • CprDecoderService — CPR 紧凑位置报告解码，奇偶帧配对 + 参考位置单帧解码
  • SimulationService — 飞机模拟器，Haversine 轨迹计算，每秒 15 架飞机位置更新 + 报文生成
  • MySQL 数据库 adsb_simulation，4 张表自动建表
  • 7 个单元测试全部通过，与 Python pyModeS 结果一致
  • H2 内存数据库模式 — 零依赖快速启动
  • Maven 阿里云镜像全局配置
  • 飞机数量运行时动态调节 API
API 接口方法功能
/api/healthGET健康检查
/api/aircraftGET飞行器列表（支持状态筛选）
/api/aircraft/positionsGET所有飞机实时位置
/api/aircraft/{icao}GET单架飞机详情
/api/aircraft/{icao}/messagesGET某飞机最近报文
/api/adsb/parsePOST解析单条 28 位 hex 报文
/api/adsb/parse/batchPOST批量解析报文
/api/simulation/startPOST启动仿真（可指定飞机数/频率）
/api/simulation/stopPOST停止仿真
/api/simulation/configPOST运行时调整飞机数量
/api/alertsGET安全告警列表
/api/statsGET全局统计数据

前端 · Vue 3 + TypeScript + Vite

页面路由功能
系统首页 / Leaflet 地图实时显示飞机 ✈ 图标 + 状态颜色 + 弹出详情 + 统计栏
飞行器列表 /aircraft Element Plus 表格 + ICAO 搜索 + 状态筛选 + 点击行弹详情卡片
报文解析 /parse 输入 28 位 hex → 调用后端解析 → 字段逐行展示 + 示例报文一键填充
安全告警 /alerts 告警列表 + 等级颜色标签 + 统计卡片（红/橙/黄/总计）
仿真控制 /control 启停按钮 + 飞机数量滑块 + 实时状态显示
数据可视化 /data ECharts 饼图 — 正常/异常飞行器比例实时刷新
技术栈：Vue 3.5 + TypeScript + Vite 8 + Pinia + Vue Router + Element Plus + Leaflet + ECharts + Axios。Vite 开发服务器自动代理 /api 到后端 localhost:8080，开发时无需跨域配置。
