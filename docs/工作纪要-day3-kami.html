核心 解码服务

  • AdsbDecoderService — 主解码引擎
  • 支持 5 种消息类型识别与解析
  • 飞机识别：呼号 + 类别（KLM1023）
  • 空中/地面位置：CPR 提取 + 高度解码
  • 空中速度：地速 + 航迹角 + 垂直速率
  • 运行状态：ADS-B 版本识别

支撑 子服务

  • CrcService — CRC-24 多项式校验
    生成多项式 0xFFFA0480
  • CprDecoderService — CPR 紧凑位置报告解码
    奇偶帧配对 / 参考位置单帧解码
    Haversine 经纬度归一化
  • AdsbParseResult — 有序 Map 输出
    前端可直接遍历展示

REST API 接口

方法 接口 功能
POST /api/adsb/parse 解析单条 28 位 hex 报文，返回有序字段 Map
POST /api/adsb/parse/batch 批量解析，支持带时间戳的顺序报文
POST /api/adsb/parse/with-ref 用参考位置解码单帧（无需奇偶配对）
